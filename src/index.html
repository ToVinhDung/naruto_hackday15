1. Soạn thảo Thư ký phân rã checklist
(Scope Decomposer Agent)		 LLM Parser, JSON Schema Validator, SHA-256 Hasher Đề xuất (Cần 2 bên ký): Tách tiêu chí Deterministic (Khách quan) vs Subjective (Chủ quan) & băm Checklist Hash.
2. Giao hàng Kỹ sư kiểm thử tự động
(Autonomous Verification Pipeline)		 Git API, Docker / Firecracker Sandbox, Test Runners, cURL, Metadata Reader Tự động chạy ngầm trong sandbox: Clone commit, chạy unit/integration test, gọi cURL kiểm tra JSON & đọc metadata Figma.
3. Nghiệm thu Giám định viên kỹ thuật
(Proposal & Proof Generation)		 Log Aggregator, Hashing Tool, Oracle Relay (ProofRegistry) Chỉ cảnh báo khi có bước không pass: Ghi Test Report Hash lên ProofRegistry on-chain; gửi khuyến nghị sửa lỗi nếu rớt test.
4. Tranh chấp Thừa phát lại trích xuất chứng cứ
(Autonomous Fact-finding Bailiff)		 Audit Trail Reader, Git Diff Analyzer, Scope Creep Detector Đề xuất phương án cho trọng tài: Tổng hợp Dispute Dossier & đề xuất tỷ lệ chia quỹ (65% Seller / 35% Buyer) chờ Trọng tài ký duyệt (HITL).
